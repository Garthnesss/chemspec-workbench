# Project Truth — ChemSpec Workbench

## One-sentence goal

A **software-only** workbench for real UV-Vis / IR (Raman optional) spectra with SDR-style plot/waterfall/peaks — honest tools, no magic compound ID.

## Feelings we protect

Immediate file→plot; honest units; shared `spectrum-core`; never market Planned as Done; Chemistry-reviewed labels.

## Done means

CSV open, zoomable spectrum, peak table, one baseline, overlay + folder waterfall, fixtures + tests, truth/agents files.

Full Phase 0 detail: `phase0.md`.
